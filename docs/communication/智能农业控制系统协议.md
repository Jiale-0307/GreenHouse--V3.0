命令整体格式：ModBus RTU

## 通信方式

串口：RS485    

网口：RJ45

## 寄存器定义

### 

| 寄存器地址    | 功能              |
|----------|-----------------|
| 系统节点板参数区 |
| 0x0000   |modbus从机地址      |
| 0x0001   | 温度1阈值           |
| 0x0002   | 温度2阈            |
| 0x0003   | 风压1阈值           |
| 0x0004   | 风压2阈值           |
| 0x0005   | 风阀角度阈值1         |
| 0x0006   | 风阀角度阈值2         |
| 0x0007   | 风阀最小角度阈值        |
| 0x0008   | 温度阈值高持续判断时间/S   |
| 0x0009   | 温度阈值低持续判断时间//S  |
| 系统节点板状态区 |                 |
| 0X0100   | 系统运行状态(0停止/1运行) |
| 0X0101   | 安全门状态(0关/1开)    |
| 0X0102   | 检修门状态(0关/1开)    |
| 0X0103   | 故障灯状态(0关/1开)    |
| 0X0104   | 照明状态(0关/1开)     |
| 0X0105   | 风帘状态(0关/1开)     |
| 0X0106   | UV灯状态(0关/1开)    |
| 0X0107   | 温度1当前温度值        |
| 0X0108   | 温度2当前温度值        |
| 0X0109   | 风压1当前气压值        |
| 0X010A   | 风压2当前气压值        |
| 0X010B   | 风阀1角度状态(0~90度)  |
| 0X010C   | 风阀2角度状态(0~90度)  |
| 0X10D    | 应急状态 （0关/1开）    |
